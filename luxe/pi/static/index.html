Receiver

In the receiver menu set Network › Network Control to “Always On”, or port 23 disappears in standby.

Display

The main zone going off is the signal — so switching off with the remote works, and so does the Apple TV turning the receiver off over HDMI. Touching the glass or turning the knob wakes it again, and so does switching the amplifier back on.

Brightness applies while you drag, so you can see what you are setting. Still press save, or it reverts on the next restart.

Brain

The Pi that listens along and recognises records. Leave it empty and the display shows volume and input only.

Volume

Half a dB per click is finely adjustable; at 2 or 3 you reach the right level quicker. The ceiling is an emergency brake — 0 dB is wide open.
